# Operit AI Agent 完整使用示例

## 概述

本文档提供了Operit AI Agent功能的完整使用示例，包括界面操作、工具调用、模板使用和性能监控等各个方面。

## 1. 基础使用示例

### 1.1 通过Agent界面执行任务

**场景：** 用户想要整理手机中的下载文件

**操作步骤：**
1. 打开Operit AI应用
2. 导航到"智能Agent"界面
3. 在输入框中输入：
   ```
   帮我整理手机下载文件夹中的文件，将图片、文档、音频、视频分别放到对应的子文件夹中
   ```
4. 点击"执行"按钮
5. 观察Agent的执行过程

**Agent执行过程：**
```
用户: 帮我整理手机下载文件夹中的文件，将图片、文档、音频、视频分别放到对应的子文件夹中

分析完成: 这是一个文件管理任务，需要扫描下载文件夹、分类文件、创建子文件夹并移动文件。

Agent: 正在生成执行计划...
计划生成完成
计划: 下载文件夹整理计划 - 自动整理下载文件夹中的文件，按类型分类存放
状态: EXECUTING

Agent: 开始执行计划...

Agent: 执行完成: 扫描下载文件夹
当前步骤: 扫描下载文件夹中的所有文件 (COMPLETED)

Agent: 脚本生成完成
当前步骤: 生成文件分类脚本 (COMPLETED)
脚本: // 扫描下载文件夹
const downloadPath = "/storage/emulated/0/Download";
const files = toolCall("list_files", { path: downloadPath });
...

Agent: 脚本执行成功
```

## 2. 模板使用示例

### 2.1 使用预设模板

**操作步骤：**
1. 在Agent界面点击"模板"按钮
2. 浏览模板列表，选择"文件整理助手"
3. 填写参数：
   - directory: `/storage/emulated/0/Pictures`
4. 点击"使用模板"

**生成的任务：**
```
帮我整理 /storage/emulated/0/Pictures 目录中的文件，将相同类型的文件放到对应的文件夹中
```

### 2.2 搜索和筛选模板

**搜索模板：**

## 3. 高级功能示例

### 3.1 复杂多步骤任务

**用户需求：**
```
我需要从GitHub API获取某个仓库的最新发布信息，提取版本号和下载链接，然后保存到本地文件，最后发送通知告诉我完成了
```

**Agent执行过程：**
1. **需求分析：** 识别为网络数据获取 + 数据处理 + 文件操作 + 通知任务
2. **计划生成：** 
   - 发送HTTP请求到GitHub API
   - 解析JSON响应数据
   - 提取版本和下载信息
   - 格式化数据并保存到文件
   - 发送完成通知
3. **脚本生成：** 自动生成包含所有步骤的JavaScript代码
4. **执行验证：** 确认每个步骤都成功完成

### 3.2 错误处理和优化

**场景：** 网络请求超时导致任务失败

**Agent处理过程：**
```
Agent: 脚本执行失败: 网络请求超时

Agent: 尝试优化步骤: 发送HTTP请求到GitHub API

Agent: 正在优化脚本...
优化策略：
- 增加请求超时时间
- 添加重试机制
- 使用备用API端点

Agent: 脚本执行成功
优化后的脚本成功获取了数据
```

## 4. 工具调用示例

```javascript

    context: "日志文件路径: /sdcard/app_logs/error.log"
```

```javascript

// 获取执行历史

    limit: 10

```

```javascript
toolCall("cancel_agent_plan", {});
```

## 8. 故障排除

### 8.1 常见问题解决

**问题1：Agent执行卡住**
```
解决方案：
1. 检查网络连接状态
2. 确认AI服务配置正确
3. 尝试取消并重新执行
4. 简化任务描述重试
```

**问题2：脚本执行失败**
```
解决方案：
1. 检查文件路径是否正确
2. 确认应用权限设置
3. 查看详细错误日志
4. 尝试使用相关模板
```

**问题3：计划生成异常**
```
解决方案：
1. 检查AI模型配置
2. 简化任务描述
3. 提供更多上下文信息
4. 重启应用重试
```

## 9. 总结

Operit AI Agent提供了强大而灵活的任务自动化能力，通过：

- **智能理解**：准确分析用户需求
- **自动规划**：生成详细执行计划
- **代码生成**：自动编写可执行脚本
- **实时执行**：流式反馈执行过程
- **错误处理**：自动优化和重试机制

用户可以通过自然语言描述复杂任务，Agent会自动完成从理解到执行的整个过程，真正实现了"说到做到"的智能助手体验。

无论是日常的文件管理、系统维护，还是复杂的数据处理、开发辅助任务，Agent都能提供高效、可靠的自动化解决方案。
