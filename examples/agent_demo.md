# Operit AI Agent 功能演示

## 功能概述

Operit AI 现在具备了完整的智能Agent功能，可以：

1. **理解用户需求** - 分析复杂的任务描述
2. **制定执行计划** - 自动生成分步骤的执行方案
3. **编写脚本代码** - 基于需求自动生成JavaScript代码
4. **执行并优化** - 运行脚本并根据结果进行优化改进

## 使用方法

### 1. 通过Agent界面使用

- 打开Operit AI应用
- 导航到"智能Agent"界面
- 在输入框中描述您的需求
- 点击"执行"按钮
- 观察Agent的执行过程和结果

### 2. 通过聊天界面使用Agent工具

您可以在普通聊天中使用以下Agent工具：

#### 执行Agent任务
```
请使用execute_agent_task工具帮我整理桌面文件
```

#### 智能脚本执行
```
请使用smart_script_execution工具为我生成一个检查系统存储空间的脚本并执行
```

## 示例场景

### 场景1：文件整理
**用户输入：**
```
帮我整理桌面文件，将相同类型的文件放到对应的文件夹中
```

**Agent执行过程：**
1. 分析需求：识别为文件操作任务
2. 制定计划：扫描桌面 -> 分类文件 -> 创建文件夹 -> 移动文件
3. 生成脚本：JavaScript代码实现文件分类和移动
4. 执行脚本：自动完成文件整理
5. 验证结果：检查整理效果

### 场景2：系统监控
**用户输入：**
```
帮我检查系统状态，包括存储空间、内存使用情况、运行的应用等
```

**Agent执行过程：**
1. 分析需求：系统信息收集任务
2. 制定计划：获取存储信息 -> 检查内存状态 -> 列出运行应用
3. 生成脚本：调用系统工具获取各项信息
4. 执行脚本：收集系统数据
5. 生成报告：整理并展示系统状态

### 场景3：网络数据处理
**用户输入：**
```
从https://api.github.com/repos/microsoft/vscode/releases/latest获取最新版本信息，并保存到文件中
```

**Agent执行过程：**
1. 分析需求：网络请求 + 数据处理 + 文件保存
2. 制定计划：发送HTTP请求 -> 解析JSON数据 -> 格式化信息 -> 保存文件
3. 生成脚本：使用网络工具和文件工具
4. 执行脚本：完成数据获取和保存
5. 验证结果：确认文件已保存

## Agent工具列表

### 1. execute_agent_task
完整的Agent任务执行工具
- **参数：** request (string) - 任务描述
- **功能：** 完整的需求分析、计划制定、脚本生成和执行流程

### 2. smart_script_execution  
智能脚本生成和执行工具
- **参数：** 
  - task (string) - 任务描述
  - context (string, 可选) - 上下文信息
- **功能：** 专注于脚本生成和执行

### 3. get_current_agent_plan
获取当前执行计划
- **功能：** 查看正在执行的Agent计划详情

### 4. get_agent_history
获取Agent执行历史
- **参数：** limit (number, 可选) - 返回记录数量，默认10
- **功能：** 查看历史执行记录

### 5. pause_agent_plan / resume_agent_plan / cancel_agent_plan
计划控制工具
- **功能：** 暂停、恢复或取消当前执行的计划

## 技术特性

### 1. 流式执行
- Agent执行过程实时反馈
- 每个步骤的状态实时更新
- 支持长时间运行的复杂任务

### 2. 错误处理和优化
- 自动检测执行错误
- 基于错误信息优化脚本
- 支持重试机制

### 3. 上下文保持
- 在执行过程中保持上下文信息
- 步骤间数据传递
- 支持复杂的多步骤任务

### 4. 安全控制
- 危险操作自动检测
- 用户权限确认机制
- 脚本执行沙箱环境

## 最佳实践

### 1. 清晰的任务描述
- 尽量详细描述您的需求
- 提供必要的上下文信息
- 指定预期的结果

### 2. 合理的任务拆分
- 复杂任务可以分步骤描述
- 每个步骤有明确的目标
- 考虑步骤间的依赖关系

### 3. 安全意识
- 涉及系统操作时仔细确认
- 重要文件操作前备份
- 理解脚本的执行内容

## 开发者信息

### 集成Agent到您的工具
如果您是插件开发者，可以通过以下方式集成Agent功能：

```javascript
// 在JavaScript插件中调用Agent
function callAgent(userRequest) {
    return toolCall("execute_agent_task", {
        request: userRequest
    });
}

// 智能脚本执行
function smartScript(task, context) {
    return toolCall("smart_script_execution", {
        task: task,
        context: context || ""
    });
}
```

### 扩展Agent能力
您可以通过以下方式扩展Agent的能力：

1. **注册新工具** - 在AIToolHandler中注册自定义工具
2. **增强分析能力** - 改进需求分析的提示词
3. **优化脚本生成** - 提供更多的API示例和模板

## 故障排除

### 常见问题

1. **Agent执行卡住**
   - 检查网络连接
   - 确认AI服务配置正确
   - 尝试取消并重新执行

2. **脚本执行失败**
   - 查看错误信息
   - 检查权限设置
   - 确认文件路径正确

3. **计划生成异常**
   - 简化任务描述
   - 提供更多上下文
   - 检查AI模型配置
